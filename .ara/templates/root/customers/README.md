# Customers

One folder per customer, `<slug>/`, lower case with hyphens. In it a `customer.md` with
who it is, who speaks for them and what is agreed, a folder `documents/` for finished
papers and a folder `history/` with one entry per contact.

What a customer is promised stands in their file and in `../company/follow-ups.md` with
the date. Access data never stands here.
