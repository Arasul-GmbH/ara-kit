# Experimente

Ein Ordner je Annahme, die geprüft wird: `NNN-<slug>/`, der Reihe nach nummeriert. Darin
eine `experiment.md` mit These, Test, Kriterium und Ergebnis, alles andere daneben.
Höchstens zwei Unterebenen, die zweite nur als Ablage je Sache. Quelltextbäume sind
ausgenommen.

Ein Experiment sagt vorher, woran es als bestätigt gilt und woran als widerlegt. Ein
Experiment ohne Kriterium für das Scheitern ist ein Projekt.

```
# NNN <die These in einem Satz>

Status: geplant | läuft | ausgewertet
Annahme: <Nummer aus company/assumptions.md>
Angelegt: JJJJ-MM-TT · Fällig: JJJJ-MM-TT

## These
## Was der Irrtum kostet, was der Test kostet
## Der Test
## Kriterium: bestätigt durch, widerlegt durch
## Log
## Ergebnis
## Entscheidung
```
